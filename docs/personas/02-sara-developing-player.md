# Sara — giocatrice in crescita

## Profilo

- Conosce le basi del VGC e sta imparando a costruire set competitivi.
- Preferisce l’interfaccia italiana; segue occasionalmente guide inglesi.
- Usa il prodotto prima delle lotte classificate e dei primi tornei.

## Scenario

Sara sa scegliere Pokémon e mosse, ma non conosce ancora tutte le combinazioni di natura, strumento, abilità e Stat Points. Ha bisogno di capire cosa sta modificando e perché un set non è utilizzabile.

## Obiettivi

- Costruire un set Champions senza conoscere a memoria tutte le regole.
- Vedere il totale Stat Points e le statistiche finali derivate.
- Capire l’effetto di una modifica con un calcolo semplice.
- Usare il calcolatore anche senza creare un team completo.
- Leggere nomi ufficiali e messaggi chiari in italiano.

## Problemi da evitare

- Select che mostrano un valore ma ne salvano un altro.
- Statistiche finali fisse dopo una modifica.
- Errore generico senza elenco delle correzioni necessarie.
- `Campo Erboso`, `Grassy` o altre label usate in modo casuale.
- Cambio lingua che cancella il set o il risultato.

## Flusso principale

1. Sceglie formato e specie.
2. Compila il set attivo nell’ordine Tera Tipo, strumento, abilità, natura, Stat Points e mosse.
3. Controlla cap e statistiche finali.
4. Apre un matchup e modifica una variabile alla volta.
5. Confronta la mossa principale con le alternative.

## Successo

Sara capisce sempre quale Pokémon sta editando, perché un input viene rifiutato e come una modifica cambia il risultato, senza dover conoscere l’inglese per usare la UI italiana.
